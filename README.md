\# JesterStep



JesterStep is a small Win32/C++ desktop shell experiment inspired by LiteStep, Blackbox, Fluxbox, and JesterWM.



It currently runs as a normal Windows app and provides a customizable panel with a right-click launcher menu.



\## Current features



\- Native Win32 panel

\- Reserves screen space using the Windows AppBar API

\- Top or bottom panel position

\- Adjustable panel height

\- Settings GUI

\- Background/text color customization

\- Launcher menu loaded from settings.ini

\- Launcher editor GUI

\- Persistent settings saved under `%APPDATA%\\JesterStep\\settings.ini`



\## Build requirements



\- Windows

\- Visual Studio 2026 Community or Build Tools

\- Desktop development with C++

\- CMake

\- Git
